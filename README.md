# chain-rag (archived)

This repo is archived. The code lives in [agentic-rag/packages/chainrag](https://github.com/trentmilam/agentic-rag/tree/main/packages/chainrag), and that is where new work happens.

chain-rag is cited retrieval over primary blockchain protocol documentation: Bitcoin, Ethereum,
Solana, Monero, Polygon and Cardano. It is built on Consilium and uses RAGpack for ingestion.

It moved because both of those live in agentic-rag.

Its commit history up to the move went with it.
